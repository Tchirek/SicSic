# 💬 SicSic

Tiny AGPL iframe comments for NormalPics, NormalDocs, this blog, and their
Cloudflare Worker/D1 comment APIs.

## What it does

Markdown comments, replies, likes, optional accounts, and a quiet `postMessage`
bridge, loaded only when the host page asks for it. Anonymous comments stay the
default path.
